A named view saves settings across all workspace pages, including experiment selection, filters, plots, configuration columns, and analysis settings. Select a view to load its saved settings and replace the current working copy.

Edits autosave the working copy and mark the view Modified. Click Update view to replace the saved snapshot, Save as new view to create another, or Revert to discard changes and reload the saved settings.

Manual selection saves specific experiments. Follow filters selects all matches and automatically includes new matching experiments when logs are rescanned every 30 seconds.

Views are saved for this log directory. Appearance, experiment annotations, and saved group/filter definitions remain independent.
